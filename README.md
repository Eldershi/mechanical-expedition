从 [1.21.1-test.12 预发布页](https://github.com/Eldershi/mechanical-expedition/releases/tag/v1.21.1-test.12) 下载客户端 MRPACK，使用支持 Modrinth 整合包的启动器导入为独立实例，并选择 Java 21。

物品栏的「饰品」按钮直接打开统一面板，可管理通用饰品、天境及其他饰品、护甲和外观。电弧炉配方的成品名称为「耐火砖泥」。
