# Native Create cobblestone generator

The build uses a Mechanical Drill to mine cobblestone at the water–lava junction. A Chute sends the output straight into a chest. Connect rotational power to the shaft on the south face.

The optional world datapack places the build with `/execute positioned <x> <y> <z> run function expedition:factory/place_cobblestone_generator`. Use an empty footprint from four blocks west to four blocks east, two blocks north to two blocks south, and from the chest level to two blocks above it. The function places the chamber, chute and chest in that area.
