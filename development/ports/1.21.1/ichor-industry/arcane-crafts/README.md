# 奥术工艺美术源

灵液工业样板的美术源来自奥术工艺自有资源，覆盖升华室配色与符文、物品和方块模型、粒子声明、声音映射和运行时材质规格。原有资源标识用于查对素材依赖。开发素材存放在本目录，游戏集成时按 1.21.1 NeoForge 的实际资源格式、注册项与依赖逐项验证。

首个样板用汐浮灵液做抽取、输送、稳压充装和设备启动。优先用现有 Create 泵、管道、储罐和加工设备跑通工序，继承奥术工艺的机壳、核心与符文美术来显示充装和启动状态。

逐文件路径、上游提交与 SHA-256 见[来源清单](SOURCE.json)。[许可](LICENSE.md)和[第三方声明](THIRD_PARTY_NOTICES.md)沿用源仓。运行时规格中引用的原版和依赖模组资源由各自安装包提供。
