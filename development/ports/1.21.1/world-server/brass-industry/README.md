# 1.21.1 工业多方块

12 座设备保留《黄铜协奏曲》Beta0.8.0ColdFix 移植的控制器配方。自动贸易终端另提供一张黄铜阶段的单个控制器配方。合金炉、液压机、工业高炉、大型电解池和自动贸易终端使用远征的结构蓝图。JEI 的 Multiblocked2 结构视图可逐层预览。旧版方块使用 1.21.1 注册名和兼容件，模型引用机械动力原版纹理。Storage Drawers 的控制器和压缩抽屉映射到 Functional Storage 对应部件。

成形后连接 FE。合金炉、液压机、工业高炉、大型电解池与贸易终端使用独立端口。其余设备经控制器输入和输出。界面显示对应的槽位和储量。合金炉与工业高炉的结构检查包括指定热态的液体燃烧室。当前测试版使用配置好的远征工序和耗电量。原包的实体爆破、动能联锁、原币制与完整工序表属于后续适配。

差速器走 Create 序列组装。黄铜板经机械手先后装入两个大齿轮和一个精密构件，一轮产出两个差速器。工业高炉和大型差分机控制器分别使用两个。

## 部署与验证

[测试实例安装器](../space/install.py)生成 MBD2 结构和配方类型，并安装客户端与专用服共享的脚本、语言和控制器配方。独立运行本目录 `build.py <输出目录> --fixtures <坐标文件>` 可得到结构与测试摆放坐标。

将坐标文件作为 `brass-fixtures.json` 放到一次性世界的专用服根目录，使用上级 `build.py --space-proof` 构建测试适配器。运行 `expeditionbrassproof` 验证 Create 选择并完成差速器的三个装配步骤、12 张控制器配方、蓝图成形和每座设施的一条实际产出。运行 `expeditionalloyproof` 可验证合金炉各端口、安山和黄铜漏斗在原生运动传送带接入及拆除时的行为，以及拆件后的恢复和重新成型。运行 `expeditionpressproof` 可验证液压机缺件检测、朝向、原生进料、压板、铸锭和拆装。运行 `expeditionworksitesproof` 可验证炼钢、电解、贸易终端的蜂港配送和拆装复位。验收适配器仅用于一次性测试服。

## 工业设施外观

合金炉占地 5×11×5 格，由控制器及 87 个建材格组成。以朝西的蓝图为基准，三面 Create 漏斗从北、西、东进固料，东面上口进液、东面下口出固料，南面底口出液。南面大型连接器用琥珀金线向接线箱输入 FE，西面检修终端打开操作界面。接入面和板片碰撞一起随控制器水平旋转。

控制器放下后，Multiblocked2 按固定坐标自动检查，确认时无需催化剂。已经成形的炉子在部件变化后复核，缺件即停止加工并恢复外壳装配件，控制器保留库存和储能。补齐缺件后可自动重新成形，重新开始工序。检查以控制器周围的固定模板为范围，针对更新的位置重新检测。

三侧采用原生 Create 漏斗。把传送带铺到漏斗正下方一格，Create 会根据带向切换该侧漏斗的形态。拆带后漏斗恢复贴墙状态；红石可单独锁定各侧。黄铜漏斗用原生筛选器的指定数量模式进行定量输入。安山与黄铜各有一份 Create 蓝图。蓝图、模板和端口共用 [摆放坐标](alloy-furnace/layout.json)。

液压机以北面控制器为基准，西侧黄铜漏斗进固料，东侧低位槽出板材和金属锭，南侧管口接收配方流体，东后侧大型连接器供电。传送带铺在漏斗正下方。控制器放下后检查固定模板，161 个搭建格齐全即可成型。刚性龙门将压头反力传至底架，后仓负责浇铸和脱模。压头和浇铸工件按当前配方进度演示，液压油回路用于解释内部结构。进液管接合金炉等设备的外部流体网络。

工业高炉分成上部进料、居中耐火炉膛和下方精炼座。上部西面黄铜漏斗进固料，西侧接氧、东侧接熔融工业铁，北侧低槽出半成品钢、南侧低管出钢水。底层两个液体烈焰人燃烧室需保持已点燃。

大型电解池在南侧接原料流体，西侧安山漏斗接配方固料，北侧低位口出铝渣。东西侧产品管口连接同一对产物罐，可在外部用 Create 智能流体管道按配方筛选，例如电解水分别筛选氢和氧。搭建时线圈下的电极位可使用安山合金块或碳电极，工序是否消耗碳电极由配方决定。

贸易终端从西侧高蜂港收货，经拆包机、西侧保险库和漏斗进入终端。结算品经东侧漏斗进入独立保险库。东侧库存链接接受原生物流请求，发货打包机将结算品打成写有目的地的包裹，交给东侧低蜂港。每个蜂港上方预留 3×3×4 格净空。配置同一物流网络与独立地址，拨开西侧拉杆使收货蜂港向下交付，东侧保持无红石输入并装入可用的物流蜂。三台设备北侧终端供玩家操作，东后侧大型连接器输入 FE。

成形后，控制器以绿灯待机、动态检视窗显示工作、琥珀灯显示等待。液压机显示压头行程或铸锭换位，熔炉从排气端排烟，电解池在电极处显示电弧。界面以冷色标记输入、金色标记输出，机器面板与 JEI 配方页使用同一套物品和流体槽样式。

装配件与机壳以 Create 及 Create Deco 的游戏资源路径为材质引用。控制器、检视窗、接口标记、原始像素图、界面及运动件的构建源位于 `visuals/`。用带 Pillow 的 Python 运行 `visuals/build_assets.py` 可重建资源，用 `--check --donor <Create JAR> --donor <Create Deco JAR> --donor <Create Crafted Beginning JAR>` 核对产物和纹理引用。带 nbtlib 的 `build.py` 生成 Multiblocked2 定义。随正式覆盖层交付的五份机器定义位于 `visuals/multiblock/`，五台设备的专用判定条件位于 `visuals/predicates/`，配方类型位于 `recipe-types/`。

合金炉的静态外壳和烈焰人动画组件位于资源目录的 `models/block/alloy_assembly`。外壳由各摆放格的部件碰撞承接，自动化接口只在对应成形部件暴露。共用的界面与未成形控制器由 `visuals/build_assets.py` 构建。

液压机的几何、建材、碰撞与端口源在 `hydropress/model.py` 和 `hydropress/pattern.py`。从本目录运行 `python -m hydropress.assets` 可用 Create JAR 生成等像素贴图、可编辑模型及剖面评审。蓝图构建脚本读取同一份建材坐标。

工业高炉、电解池和贸易终端的几何、端口、占位与材质源位于 `worksites/`。使用 `python -m worksites.assets --help` 查看可编辑模型和评审预览的导出方法。
