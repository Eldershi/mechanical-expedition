# 1.21.1 工业多方块

12 座设备的控制器使用《黄铜协奏曲》Beta0.8.0ColdFix 的合成格、材料数量和产量，结构使用对应蓝图的逐格布局。JEI 的 Multiblocked2 结构视图可逐层预览。旧版方块使用 1.21.1 注册名和兼容件，模型引用机械动力原版纹理。Storage Drawers 的控制器和压缩抽屉映射到 Functional Storage 对应部件。

成形后连接 FE。物品和流体通过控制器输入与输出，界面显示对应的槽位和储量。合金炉与工业高炉的结构检查包括指定热态的液体燃烧室。当前测试版使用配置好的远征工序和耗电量。原包的实体爆破、液压机活塞动作、动能联锁、原币制与完整工序表属于后续适配。

差速器走 Create 序列组装。黄铜板经机械手先后装入两个大齿轮和一个精密构件，一轮产出两个差速器。工业高炉和大型差分机控制器分别使用两个。

## 部署与验证

[测试实例安装器](../space/install.py)生成 MBD2 结构和配方类型，并安装客户端与专用服共享的脚本、语言和控制器配方。独立运行本目录 `build.py <输出目录> --fixtures <坐标文件>` 可得到结构与测试摆放坐标。

将坐标文件作为 `brass-fixtures.json` 放到一次性世界的专用服根目录，使用上级 `build.py --space-proof` 构建测试适配器。运行 `expeditionbrassproof` 验证 Create 选择并完成差速器的三个装配步骤、12 张控制器配方、原布局成形和每座设施的一条实际产出。验收适配器仅用于一次性测试服。

## 工业设施外观

合金炉占地 5×11×5 格，由控制器及 87 个建材格组成。以朝西的蓝图为基准，三面 Create 漏斗从北、西、东进固料，东面上口进液、东面下口出固料，南面底口出液。南面大型连接器以向机器供电的模式给接线箱输入 FE，西面检修终端打开操作界面。接入面和板片碰撞一起随控制器水平旋转。

控制器放下后，Multiblocked2 按固定坐标自动检查，确认时无需催化剂。已经成形的炉子在部件变化后复核，缺件即停止加工并恢复外壳装配件，控制器保留库存和储能。补齐缺件后可自动重新成形，重新开始工序。检查以控制器周围的固定模板为范围，针对更新的位置重新检测。

三侧采用原生贴墙或传送带漏斗，可分别接传送带及锁定红石。黄铜漏斗用原生筛选器的指定数量模式进行定量输入。安山与黄铜各有一份 Create 蓝图。蓝图、模板和端口共用 [摆放坐标](alloy-furnace/layout.json)。

液压机、工业高炉、大型电解池和自动贸易终端使用带检视窗的控制器。银色方口表示共用物品接口，黄铜触点表示 FE 输入，铜质圆口的青色标记表示流体输入，金色标记表示流体输出。接口以控制器的面为单位，由各面现有能力处理。自动贸易终端的窗口和交接盘随交易工序运转，玩家在机器界面投入货物或代币并领取结算。

成形后，控制器以绿灯待机、动态检视窗显示工作、琥珀灯显示等待。液压机在龙门滑车旁显示压头行程，熔炉从排气端排烟，电解池在电极处显示电弧。界面以冷色标记输入、金色标记输出，机器面板与 JEI 配方页使用同一套物品和流体槽样式。

装配件与机壳以 Create 及 Create Deco 的游戏资源路径为材质引用。控制器、检视窗、接口标记、原始像素图、界面及运动件的构建源位于 `visuals/`。用带 Pillow 的 Python 运行 `visuals/build_assets.py` 可重建资源，用 `--check --donor <Create JAR> --donor <Create Deco JAR> --donor <Create Crafted Beginning JAR>` 核对产物和纹理引用。带 nbtlib 的 `build.py` 生成 Multiblocked2 定义。随正式覆盖层交付的五份机器定义位于 `visuals/multiblock/`，合金炉专用判定条件位于 `visuals/predicates/`，配方类型位于 `recipe-types/`。

合金炉的静态外壳和烈焰人动画组件位于资源目录的 `models/block/alloy_assembly`。外壳由各摆放格的部件碰撞承接，自动化接口只在对应成形部件暴露。共用的界面与未成形控制器由 `visuals/build_assets.py` 构建。
