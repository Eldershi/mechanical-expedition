# 地月设施与气密供氧

Minecraft 1.21.1、NeoForge 21.1.267、Java 21。客户端和服务端使用同一份结构、任务和适配配置。

## 装配和运行

在 JEI 的 Multiblocked2 结构视图检查控制器和摆放层。框架、结构板和隔热窗都是可生存制造的航天建材。先用 Ad Astra 载人火箭探访地月表面与轨道，再为一支 FTB 队伍在各维度右键登记端点。

| 设施 | 地点 | 操作和消耗 |
| --- | --- | --- |
| 卫星收发站 | 地球轨道、月球轨道 | 空手右键，消耗 8,000 FE。登记地面航标。月球站额外给出原生月球地牢坐标。 |
| 火箭发射台 | 地球轨道、月球轨道 | 装货、放入可复用载具和火箭燃料桶。每批 32,000 FE 和一桶燃料。 |
| 太空电梯 | 地球、月球及二者轨道 | 持控制器发货，空手潜行右键乘坐。一次 4,000 FE。 |
| 轨道空投炮 | 地球轨道、月球轨道 | 向同星球的航标发送，落点上方须畅通。每批 12,000 FE。 |
| 异界门 | 月球地面 | 完成三批双向轨道货运，并实地调查月球地牢。一次 16,000 FE。 |

一批最多八格。菜单第一排前八格待发，第二排前八格收货。发射台第三排前两格为可复用载具与燃料桶。控制器底面可抽出到货和空桶，顶面和侧面可输入。地面收货航标的各面均可抽出货物。持货运控制器潜行右键开启循环发货。到货端未加载、落点受阻或收货区满时，货物继续等待。货物保存在存档中。原控制器移除后，队伍可以在同一维度重建对应端点；`/spacefreight recover` 将等候中的货物退回起点有空位的收货区。

月球异常凭据在实地调查时取得。从异界用它或用 `/spacefreight return` 返回原月面门位置附近。原生异界传送台也可用于撤离。

## 两套护甲

- 机素防护穿戴太空呼吸装备并带已启用的 Giselle 氧气罐。Ad Astra 氧气装载机补气，炎热地表需备耐火配置。
- 机巧新生的四件气密甲使用气罐组。保持生命维持模块在主手，先对副手的气罐组在空中右键指定第一格，再对副手的气密头盔使用模块完成安装。第一罐用原生气密舱口充自然空气，其余气格支持抗性、回复和推进。高温另用气密耐热内衬升级胸甲。

## 构建和验证

使用带 `nbtlib` 的 Python 和 Java 21 执行 `install.py --client <client> --server <server> --java <java>`，部署到停止的测试实例。结构层布局在 `structures.json`，可用 `build_structures.py <out> --fixtures <json>` 生成结构和装配坐标。配方和任务位于 `overlay`，服务端状态和事件逻辑位于 `src`。

在一次性世界中，可给上级 `build.py` 加 `--space-proof`。将生成的装配坐标 JSON 放到专用服根目录并命名为 `space-fixtures.json`。执行 `expeditionspaceproof run` 检查结构与配方、自动装货、双向三批、接收端满载和交付计数。正常保存关闭并重启后执行 `expeditionspaceproof reload` 验证货物和进度持久化。正式测试包使用普通构建。
