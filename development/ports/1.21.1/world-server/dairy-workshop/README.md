# 乳品车间

适用于远征 1.21.1 的两头牛乳品车间，使用 Create Rancher 的集奶地板和机械动力的流体管路。水车驱动两台动力泵，先将牛奶送入八桶缓冲罐，再经过注液器灌成 Farmer’s Delight 的奶瓶。

在入口一侧的上层木桶放入玻璃瓶，下层木桶收取奶瓶。下层出口可接漏斗、仓储或打包机。集奶地板上有成年牛、区块在运行且储罐有空间时，牛奶会持续补充。牲畜栏设有栅栏门。

管理员可将本目录作为数据包安装到世界的 `datapacks`，选取地面上方空出的 13 × 9 × 6 区域，再从其西北角地板位置执行 `/execute positioned <x> <y> <z> run function expedition_dairy:build`。车间向东和南展开，施工作业前让区块完成加载。此函数只在占地与同列的空白天空一致时施工，牛会随车间生成。
