# ME无线集线器

<Row gap="20">
<BlockImage id="expatternprovider:wireless_hub" scale="6"></BlockImage>
</Row>

ME无线集线器的功能与<ItemLink id="expatternprovider:wireless_connect" />相同，但最多可以同时连接 8 个集线器或连接器。

## 连接配置

ME无线集线器拥有 8 个端口。使用<ItemLink id="expatternprovider:wireless_tool" />建立连接时，会自动寻找空闲端口。

所有端口都被占用时，必须先点击“X”按钮，手动断开一个连接，才能建立新连接。
